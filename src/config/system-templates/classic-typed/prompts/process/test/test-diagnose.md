Run or inspect the focused target to classify the accepted brief's coverage and behavior. Record the target, commands, observations, classification and current status in `status.md`. On fresh entry or re-entry, correct and adequately covered behavior needs no manufactured failure, test/source change or metadata delta.

Select `coverage_ready` only for meaningful adequate coverage of the brief with passing focused tests, `coverage_gap` for absent meaningful coverage, `failing_test` for an observed failing test or fixture, `blocked` when diagnosis needs unavailable input, or `failed` for a conclusive failure. Passing diagnosis still proceeds to verification-owned acceptance.
