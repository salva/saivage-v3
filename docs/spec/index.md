# Functional Specifications

This directory is the current functional specification authority for Saivage v3.

Use these documents to decide what the system must do from the user and runtime point of view. Implementation plans, temporary reviews, and migration notes belong in `docs/working/<date>/` while in progress and in `docs/old/` when superseded.
