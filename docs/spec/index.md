# Functional Specifications

This directory contains the current functional specification entries for Saivage v3.

The canonical main documentation set is `docs/spec/system-specification.md`, `docs/spec/operator-ui.md`, `docs/architecture/system-architecture.md`, and `README.md`. Use the specification documents here to decide what the system must do from the user, runtime, and UI point of view; use the [architecture index](../architecture/) to navigate supporting design reference and provenance. Implementation plans, temporary reviews, and migration notes belong in `docs/working/<date>/` while in progress.
